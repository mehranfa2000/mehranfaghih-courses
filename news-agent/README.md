# اینتلی‌نیوز — ایجنت هوشمند اخبار

یک ایجنت هوش مصنوعی که بر اساس **کلیدواژه‌های شما**، هر **یک ساعت** اخبار را از منابع داخلی و خارجی جستجو، استخراج و به صورت:

> **تیتر + خلاصه + تاریخ شمسی + ساعت + لینک + نام ناشر**

نمایش می‌دهد و به کانال تلگرام ارسال می‌کند.

---

## ✨ ویژگی‌ها

- 🔑 **کلیدواژه دلخواه**: توسط شما وارد می‌شود، چندین کلیدواژه همزمان
- 🌍 **منابع داخلی و خارجی**:
  - داخلی: ایرنا، ایسنا، مهر، تسنیم، فارس، تابناک، خبرآنلاین، اقتصادآنلاین
  - خارجی: BBC فارسی، DW، یورونیوز، رادیو فردا + گوگل نیوز فارسی و انگلیسی (۳۰+ منبع)
- ⏰ **جستجوی خودکار هر ساعت** (قابل تنظیم: ۱۵ دقیقه تا ۱۲ ساعت)
- 📰 **استخراج هوشمند**: تیتر، خلاصه (با trafilatura + BeautifulSoup)، تاریخ جلالی، ساعت، لینک، ناشر
- 🤖 **ارسال به تلگرام**: حالت تکی یا خلاصه (Digest)
- 💾 بدون نیاز به دیتابیس سنگین - ذخیره JSON + deduplication
- 🎨 داشبورد فارسی مدرن، ریسپانسیو، با تم دارک

## 📁 ساختار پروژه

```
news-agent/
├── backend/
│   ├── app.py              # FastAPI اصلی + زمان‌بند APScheduler
│   ├── fetcher.py          # جستجوی Google News RSS + RSS مستقیم
│   ├── sources.py          # لیست منابع داخلی/خارجی
│   ├── telegram_bot.py     # ارسال فرمت شده به تلگرام
│   ├── database.py         # ذخیره JSON
│   ├── models.py
│   └── requirements.txt
├── frontend/
│   └── index.html          # داشبورد کامل SPA
└── data/                   # keywords.json, news.json, config...
```

## 🚀 اجرای محلی

```bash
cd news-agent/backend
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
# سپس http://localhost:8000 را باز کنید
```

## 🔧 نحوه کار

1. **کلیدواژه بده**: مثلا `هوش مصنوعی`, `ارز دیجیتال`, `OpenAI`
2. **تنظیم بازه**: پیش‌فرض هر ۶۰ دقیقه
3. **جستجوی فوری**: دکمه جستجوی فوری برای تست آنی
4. **تلگرام**:
   - به @BotFather برو، /newbot بزن، توکن بگیر
   - ربات را ادمین کانال کن
   - توکن و @channel را در پنل وارد کن، ذخیره + تست
5. **خودکار**: ایجنت هر ساعت اجرا می‌شود، خبر جدید را به تلگرام می‌فرستد

## ⚙️ API

- `GET /api/keywords` - لیست کلیدواژه‌ها
- `POST /api/keywords` {keyword}
- `GET /api/news?limit=100&source_type=domestic`
- `POST /api/fetch` - جستجوی دستی
- `POST /api/fetch-now` - اجرای background
- `GET/POST /api/telegram` - تنظیمات تلگرام
- `POST /api/telegram/test`
- `GET /api/stats` - آمار
- `GET /api/logs`

## 🔐 امنیت توکن تلگرام

توکن در فایل `data/telegram.json` ذخیره می‌شود و در API به صورت masked برگردانده می‌شود.

## 🛠️ تکنولوژی

- FastAPI + APScheduler
- feedparser + trafilatura + BeautifulSoup4
- jdatetime برای تاریخ شمسی
- Vanilla JS frontend (بدون build)
